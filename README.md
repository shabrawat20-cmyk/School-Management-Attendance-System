# School Management & Attendance System

![School Management & Attendance System](https://github.com/shabrawat20-cmyk/School-Management-Attendance-System/raw/main/school-management-banner.png)


A Python and MySQL based School Management & Attendance System for managing  students, classes, attendance records, reports, and data export.

## Features

- Student Management
  - Add student
  - View students
  - Search student
  - Update student details
  - Delete student
- Class Management
- Attendance Management
  - Take daily attendance
  - Update attendance
  - Attendance history
  - Attendance percentage
  - Low attendance report
- Search students by name
- School Dashboard
- Export student and attendance data to CSV
- MySQL database integration

## Technologies Used

- Python
- MySQL
- PyMySQL
- Pandas
- Jupyter Notebook
- SQL

## Project Files

| File | Description |
|---|---|
| `SCHOOL-MANAGEMENT & Attendance-SYSTEM.py` | Main Python application |
| `SCHOOL-MANAGEMENT & Attendance-SYSTEM.ipynb` | Jupyter Notebook version |
| `SCHOOL-MANAGEMENT & Attendance-SYSTEM.sql` | SQL database setup |

## How to Run

### 1. Install required libraries

```bash 
pip install pymysql pandas 
```
### 2. Setup MySQL
Make sure MySQL is installed and running on your system.

Run the SQL file:
```bash
SCHOOL-MANAGEMENT & Attendance-SYSTEM.sql
```

### 3. Run the Python application

```bash
python "SCHOOL-MANAGEMENT & Attendance-SYSTEM.py"
```
